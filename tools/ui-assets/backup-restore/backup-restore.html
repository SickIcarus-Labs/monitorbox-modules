Configuration management

Backup & Restore

Portable configuration JSON. Signed modules are reinstalled during recovery; telemetry history is not backed up.

Configuration

Administrator authentication

Backup and restore require an administrator session.

Backup

Download configuration

Export the current appliance settings, signed module selections, dashboard preferences and provider credentials as a single JSON file.

Contains plaintext provider credentials. Store this file securely. It does not contain historical telemetry or the administrator password.

Restore

Restore configuration

Upload a configuration JSON to validate and replace application settings through the existing signed lifecycle. The current administrator password is retained.

A backup saved on Beta or Dev can opt back into its original channel after validation.

Restore discards historical telemetry and rebuilds the selected signed modules. It does not merge settings.

Advanced: edit or save configuration JSON

For controlled configuration edits. Save preserves history; Restore replaces configuration and discards history.
